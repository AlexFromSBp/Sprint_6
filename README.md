                        Sprint_6|Тестирование сервиса «Яндекс.Самокат»

Тестовые сценарии:

1. Выпадающий список в разделе «Вопросы о важном»: когда нажимаешь на стрелочку, открывается соответствующий текст. 
2. При заказе самоката проверить весь флоу позитивного сценария с двумя наборами данных; 
Проверить точки входа в сценарий, их две: кнопка «Заказать» вверху страницы и внизу.

В директории helpers расположены локаторы, тестовые данные, urls.
В директории pages прописаны методы взаимодействия: общие, домашней и страницы заказа.

Фреймворк: pytest, selenium, allure, Mozilla Firefox, локаторы спроектированы на POM.
